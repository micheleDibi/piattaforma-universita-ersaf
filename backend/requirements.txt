# Hashing delle password. Si usa bcrypt DIRETTAMENTE, senza passlib:
#   - passlib e' fermo all'ultima release del 2020 e si rompe con bcrypt >= 4.1
#     (AttributeError su __about__), quindi imporrebbe un pin `bcrypt<4.1`
#     permanente;
#   - servono tre funzioni in tutto, e CryptContext aggiunge uno strato proprio
#     dove dobbiamo controllare dove avviene il troncamento a 72 byte.
# Vedi backend/src/security/password.py.
bcrypt>=4.0,<5

# tutte le route sono sync e i background task sincroni girano nel threadpool,
# dove una chiamata bloccante non ferma l'event loop. Niente aiosmtplib.
